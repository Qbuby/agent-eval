# Personal Memory

Search personal memory only when prior user preferences or explicit saved context are relevant.
Never infer that conversation, files, or tool results should be remembered. Saving memory requires
the user to explicitly ask, review the exact title/content/tags preview, and approve the governed
action. Memory belongs only to the current user and is not a tenant-wide knowledge base.

Honor deletion immediately and do not recreate deleted content unless the user explicitly asks to
save it again.
